# Contributing to Awesome Free AI Tools

Thanks for helping keep this list honest. Suggestions are welcome — as pull requests or as issues — but every addition has to pass the same bar as the tools already listed.

## How to suggest a tool

Open a pull request (or an issue if you prefer) that adds one row to the right category table:

```
| Tool Name | Best for | Free-tier limit | Link |
```

Include in your PR description or issue:

1. **The tool's official homepage link** — no affiliate links, no referral codes, no tracking parameters.
2. **Proof of a real free tier** — a link to the tool's official pricing page showing a free plan. A free trial that expires does not count.
3. **The verified free limit, with its source** — for example "300 minutes/month (otter.ai/pricing)". If the limit is not publicly stated anywhere, write "Free tier available" and nothing more specific. Never invent a number.

## Rules for additions

- **Real free tier only.** No trial-only tools, no invite-only tools, no paid-only tools, no "free with card upfront" plans.
- **General availability.** Student-only, educator-only, or startup-program-only free tiers do not count.
- **Official links only.** Homepage or official pricing/docs pages. No blog roundups, no referral URLs.
- **One row, right category.** Keep the table format (`Tool | Best for | Free-tier limit | Link`). Keep "Best for" short — one line.
- **No hype.** Describe what the tool is best for in plain words. No superlatives, no marketing copy.

## How to report a change or removal

If a tool removed its free tier, shrank its limit, or shut down, open an issue or PR with a link to the official announcement or pricing page. The entry will be updated or removed.

## Style

- Keep the README's tone plain and honest — the same standard as the "Honest Notes" section.
- Check your links: every link must resolve to the tool's official site.
